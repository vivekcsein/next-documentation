# Array in JavaScript

An array is a list of values. It is a data structure that stores a collection of items. You can use an array to store a set of data, like a list of numbers, names, or even photos.

```js
const numbers = [1, 2, 3, 4, 5];
const names = ["Alice", "Bob", "Charlie"];
const photos = [
  "https://example.com/alice.jpg",
  "https://example.com/bob.jpg",
  "https://example.com/charlie.jpg",
];
